# Frontend

Not started yet. This gets built once `backend`'s `POST /query` endpoint
works end-to-end (real retrieval + real generation, not stubs) - no point
styling a UI against an endpoint that returns 501s.

Goal: a clean, minimal, non-generic-AI-demo interface - a question box,
a grounded answer, and its cited sources. No purple gradients, no
sparkle/robot iconography, no "Welcome to my AI Assistant" hero copy.

Tech choice and its own `tests/` directory get decided when we get here.
